# Hermes Agent 可观测宪章调研总览

## Agent 信息

| 项目 | 说明 |
|------|------|
| Agent 名称 | Hermes Agent (NousResearch) |
| 技术栈 | Python, Plugin 架构 |
| Hook 接入方式 | 内嵌 Python plugin (`~/.hermes/plugins/`) |
| 数据源 | Plugin hooks 回调参数 |
| 可观测插件 | `observ-hermes` |

## 条款支持矩阵

| 条款 | 状态 | 数据源可靠性 | 说明 |
|------|------|-------------|------|
| C1 Turn/Root Span | ✅ 支持 | 高 | `on_session_start`/`on_session_end` 提供完整 session 生命周期 |
| C2 LLM 请求 | ✅ 支持 | 高 | `pre_llm_call`/`post_llm_call` 提供 model、conversation_history |
| C3 Tool 调用 | ✅ 支持 | 高 | `pre/post_tool_call` 提供 tool_name、args、result、duration_ms |
| C4 MCP 工具 | ✅ 支持 | 高 | 通过 `mcp__` 前缀自动分类 |
| C5 Skill 工具 | ⚠️ 部分支持 | 中 | Hermes 无独立 skill 概念，plugin-registered tools 可视为 skill |
| C6 Subagent | ✅ 支持 | 高 | `subagent_stop` 提供 parent_session_id、child_role、child_status、duration_ms |
| C7 跨 Trace 关联 | ❌ 不支持 | — | 子 agent 无独立 trace_id 暴露 |
| C8 Compaction | ⚠️ 推断支持 | 中 | 通过 conversation_history 长度变化推断（启发式，非精确） |
| C9 Messages | ✅ 支持 | 高 | `pre_llm_call` 提供完整 conversation_history（OpenAI 格式） |
| C10 Delta Input | ✅ 支持 | 高 | 通过 history 长度差值计算增量 |
| C11 Token 语义 | ⚠️ 部分支持 | 低 | Hooks 未原生传递 token counts，依赖 `**kwargs` 未来扩展 |
| C12 System Instructions | ❌ 不支持 | — | System prompt 不在 hook 参数中暴露 |
| C13 并发工具 | ✅ 支持 | 高 | `pre_tool_call` 并发触发可检测（pending count > 1） |
| C14 Cancel/Retry | ⚠️ 部分支持 | 中 | `on_session_end` 的 `interrupted=True` 可检测取消 |
| C15 脱敏与截断 | ✅ 支持 | 高 | 插件侧实现 20K 截断 + `...[TRUNCATED]` |

## 数据源详情

### 高可靠性数据源

| Hook | 参数 | 对应语义 |
|------|------|----------|
| `on_session_start` | session_id, model, platform | C1 session 标识 |
| `pre_llm_call` | session_id, user_message, conversation_history, model, is_first_turn | C2, C9, C10 |
| `post_llm_call` | session_id, assistant_response, conversation_history, model | C2, C9 |
| `pre_tool_call` | tool_name, args, task_id | C3 |
| `post_tool_call` | tool_name, args, result, task_id, duration_ms | C3, C4-C6 |
| `subagent_stop` | parent_session_id, child_role, child_summary, child_status, duration_ms | C6 |
| `on_session_end` | session_id, completed, interrupted, model, platform | C1 |

### 已知缺失

1. **Token counts (C11)**: Hermes hook 未传递 `input_tokens` / `output_tokens`。需等待 Hermes 更新或通过 `**kwargs` 扩展
2. **System prompt (C12)**: 不在任何 hook 参数中暴露
3. **Cross-trace linking (C7)**: 子 agent 的 trace_id 不可获取
4. **精确 Compaction 时间 (C8)**: 仅能通过 history 长度变化推断，无明确 compaction 事件

## 正面证据

- Hermes 提供 10 种生命周期 hooks，覆盖完整 session → turn → tool 链路
- `duration_ms` 原生传入 `post_tool_call` 和 `subagent_stop`，无需自行计时
- `conversation_history` 为 OpenAI 格式，与 C9 要求直接对齐
- 错误隔离：plugin 崩溃不影响 agent 主流程
- `subagent_stop` 在父线程 marshalling，无并发回调问题

## 缓解措施

| 缺失 | 缓解 |
|------|------|
| Token counts | 监控 `**kwargs` 新增字段；提供 estimation fallback |
| Compaction 精度 | 设置 20% 阈值避免误判；标记为 `trigger=heuristic` |
| C7 跨 trace | 保留 `agentic.subagent.role` + `duration_ms` 作为弱关联 |
