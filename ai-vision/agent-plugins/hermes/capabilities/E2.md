# E2 上游调用 TRACEPARENT 串联

- **评分**: ⚪
- **结论**: Hermes v0.18.2 observer callback contract 没有 `TRACEPARENT`、HTTP inbound context 或等价上游 parent span 字段；常驻 observer pipeline 也不读取当前 shell 环境来猜测关联。因此本轮 E2 为数据源不适用，而不是未实现。
- **代码证据**:
  - `hermes/observ_hermes/pipeline.py:59` — pipeline 只按 observer hook payload 的 session ID 归一化事件，没有 traceparent 输入。
  - `hermes/docs/HERMES_V0_18_2_HOOK_CONTRACT.md:22` — documented callback surface 列出 session/API/tool/subagent hooks，没有 W3C propagation hook。
- **Replay/source 证据**:
  - `hermes/tests/fixtures/hooks/v0.18.2/observer_envelopes.json:1` — pinned envelope 仅包含 observer schema 与 session/lifecycle 数据，没有上游 W3C context。
  - `hermes/CAPABILITIES.md:5` — 当前 pipeline 评估对象是 observer callbacks，不把 replay 进程环境作为历史 source。
- **数据源缺失根因**: Hermes v0.18.2 observer SDK 不暴露上游 trace context，且常驻 observer 可能处理多个 session；使用进程级 `TRACEPARENT` 会造成错误串联。未来 host contract 提供 session-scoped context 后再评估。
