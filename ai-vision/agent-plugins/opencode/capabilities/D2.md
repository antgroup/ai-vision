# D2 同步子 agent 调用识别 {#d2}

- **评分**: ✅
- **结论**: OpenCode 1.17.18 的 `task` 工具会创建带 `info.parentID` 的子 session。共享 hooks 将该委派建模为父 Turn 下的 `agent SyncAgent` AGENT span，子 session 不再生成独立 Turn root，其 LLM / TOOL 直接挂在 SyncAgent 下。
- **代码引证**:
  - `opencode/observ-opencode/src/hooks/tool.ts:1-451`：`task` 创建 `gen_ai.span.kind=AGENT` / `gen_ai.operation.name=invoke_agent` 的 `agent SyncAgent`
  - `opencode/observ-opencode/src/hooks/session.ts:1-182`：用真实 `session.info.parentID` 绑定 child session，不使用全局“下一个 session”猜测
  - `opencode/observ-opencode/src/hooks/index.ts:1-700`：子 session 复用 SyncAgent span/context 作为逻辑 turn root
- **Replay 例子**: `~/.aivision/ocd/golden/replays/spans_subagent.jsonl` — 同一 trace 中存在 `Turn 1 → agent SyncAgent → chat Qwen3-Coder... / tool bash`，并携带 parent/child thread id。
