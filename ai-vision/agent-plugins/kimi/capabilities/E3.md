# E3 非真实用户 / 外部触发归因识别

- **评分**: ❌
- **结论**: 当前 Kimi 未实现 `AIVISION_META_TRIGGER` / `meta.trigger` 配置输入，也未在 Resource 写入 `ant.meta.trigger` 或在逻辑 Turn root 写入 `agentic.turn.trigger`。本轮按统一默认基线评为 ❌。
- **代码证据**:
  - `kimi/kimihooks/src/common/edition.rs:277-323` — 当前运行时配置结构没有 meta-trigger 字段。
  - `kimi/kimihooks/src/bin/kimihooks_replay.rs:241` — replay export context 没有 E3 trigger 输入。
  - `kimi/kimihooks/src/hooks/stop.rs:332-377` — 生产 Stop 与现有 replay 共用 Resource/export 路径，但没有外部触发归因处理。
- **Replay/source 证据**:
  - `kimi/kimihooks/src/bin/kimihooks_replay.rs:287` — replay 使用当前三信号 wrapper 输出，未保存或消费 `meta.trigger`。
  - 当前 Kimi wire fixtures/replays 没有 `ant.meta.trigger` 或 `agentic.turn.trigger` 的版本化正向样本。
- **数据源与缺失原因**: 本轮新增的 E3 输入契约尚未接入 Kimi 的配置、hook payload 或 wire/replay schema，因此是实现缺口。不能从 Kimi 的 Turn、wire 文本、用户名或工具名称推断真实用户；未来必须使用显式环境/配置或宿主结构化 source。
- **边界**: 允许外部 `automation` / `interactive` / `unknown` 三值，非法值归一化为 `unknown`；Turn 级宿主枚举独立维护，不把 Resource 值复制到所有 span。
