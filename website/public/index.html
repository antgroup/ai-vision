开始前的几个问题。

已有 Langfuse SDK，可以直接接入吗？+

可以。保留已有 SDK、Callback 与插桩代码，切换 Server Endpoint 和接入凭据即可，无需重新埋点。兼容范围为 SDK 的 OTLP 轨迹上报；Prompt 管理、离线实验和历史数据迁移按具体需求评估。

我只是使用 Agent，也能用吗？+

可以。为已支持的 Agent 应用安装采集插件，照常使用后回看任务。你可以从一个熟悉的任务开始，检查工具执行、上下文、耗时和 Token 用量，不必先掌握观测术语。

Langfuse SDK 和 NVIDIA NeMo Relay 怎么选？+

它们是框架层可选的接入方式。已有 SDK 埋点可以继续使用；使用 Relay 的团队，也可以采集框架运行数据后导出到 AI Vision。按已有采集方案选择，后续还会兼容更多主流采集方式与 SDK。

观测与诊断，会自动替我修好 Agent 吗？+

平台提供执行记录和诊断依据，帮助你找到改进方向。由你结合测试与业务验收确认问题、决定调整方式，再通过同类任务观察改进效果。

已有埋点，直接沿用。

保留 Langfuse SDK、Callback 与插桩代码，切换接入地址和凭据，新的轨迹即可上报到 AI Vision。

LANGFUSE_PUBLIC_KEY=<Public Key>
LANGFUSE_SECRET_KEY=<Secret Key>
