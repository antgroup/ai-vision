# E3 非真实用户 / 外部触发归因识别

- **评分**: ❌
- **结论**: 当前 OpenClaw 未实现统一的 `AIVISION_META_TRIGGER` / `meta.trigger` 输入及 `ant.meta.trigger` Resource 输出，也未实现独立的 `agentic.turn.trigger` 宿主事实字段。本轮按用户指定的默认未实现基线评为 ❌，不因常驻 gateway 身份而推断用户真实性。
- **代码证据**:
  - `openclaw/observ-openclaw/src/config.ts:322-330` — 当前配置读取 Resource attributes，但没有 `meta.trigger` 配置解析或 `AIVISION_META_TRIGGER` 优先级处理。
  - `openclaw/observ-openclaw/src/telemetry.ts:80-115` — 当前 Resource builder 没有 `ant.meta.trigger` 归因输出。
  - `openclaw/observ-openclaw/src/hooks/session.ts:201-251` — 当前 Turn root 属性没有 `agentic.turn.trigger`。
- **Replay/source 证据**:
  - `openclaw/openclaw-replay/src/raw-envelope.ts:1-20` — replay envelope 类型没有 E3 meta-trigger source 字段。
  - 当前 OpenClaw replay/Golden 样本没有 `ant.meta.trigger` / `agentic.turn.trigger` 正向输出，不能把 HTTP/diagnostic context 当作 E3 证据。
- **数据源与缺失原因**: 当前 OpenClaw plugin/replay contract 没有统一记录外部任务归因和宿主 Turn trigger。E3 不允许从消息内容、session key、gateway 进程 cwd 或用户名推断真实用户；应在显式配置/raw callback source 接入后再采集。
- **边界**: `ant.meta.trigger` 是 Resource 级外部归因，`agentic.turn.trigger` 是 Turn root 级宿主观察；二者允许不一致。常驻进程不构成免除 E3 的理由，本轮不修改生产/replay 实现。
