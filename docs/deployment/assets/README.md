# OpenShell automatic setup screenshots

These four natural screenshots support the Chinese and English installation
guides. Their [manifest](openshell-bootstrap-manifest.json) records original and
asset hashes, locked dirty-worktree frontend source, the accepted CLI hash and
local runtime evidence. Lossless WebP conversion preserves the original JPEG's
decoded RGB pixels, without crop, redrawing or retouch.

The Chinese introduction/default and English restored outcome belong to the
single accepted automatic installation. The English introduction is real backend
preparation in another Space, whose command was not executed. Local Linux ARM64
execution on a macOS ARM64 Docker VM used prepared upstream caches and a loopback
source-QA registry. This does not qualify a published package, fully cold install,
private-native delivery or another architecture/host.

The source base commit alone does not contain the new implementation. Record the
accepted product commit before publishing this feature or its documentation.
