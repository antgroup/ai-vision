# E2 上游调用 TRACEPARENT 串联

- **评分**: 🟡
- **结论**: OpenClaw 已有 HTTP trace bridge，可捕获 W3C `traceparent` header；同时生产 Turn 可消费 host diagnostic parent context，并对 SOFA context 创建 upstream span link。当前代码尚未把捕获到的 W3C `traceparent` 直接解析并用于 Turn 的 `traceId`/`parentSpanId`，因此只有部分上游关联能力，不能评为 ✅。
- **代码证据**:
  - `openclaw/observ-openclaw/src/trace-bridge.ts:16` — `UpstreamTraceHeaders` 定义 W3C `traceparent`/`tracestate`，并与 SOFA/B3 header 一起捕获。
  - `openclaw/observ-openclaw/src/trace-bridge.ts:40` — trace interceptor 注册 `traceparent` header capture。
  - `openclaw/observ-openclaw/src/hooks/session.ts:47` — `diagnosticParentContext` 严格校验 32 位 trace ID、16 位 span ID，并建立 remote OTel context。
  - `openclaw/observ-openclaw/src/hooks/session.ts:175` — 上游 SOFA context 被转换为 span link；这不是 W3C parent replacement。
- **Replay/source 证据**:
  - `openclaw/observ-openclaw/scripts/subagent-correlation.test.ts:1-260` — 测试通过 OTel upstream span context 验证 Turn parent 与 child topology。
  - `openclaw/observ-openclaw/src/hooks/session.ts:177-209` — SOFA link 和 diagnostic parent 的生产路径证据；W3C header 到 Turn parent 的直接桥接仍缺。
  - `openclaw/openclaw-replay/src/raw-envelope.ts:1` — replay raw envelope 需要后续明确保存 W3C header，当前不能把运行时 HTTP header隐式带入离线 replay。
- **边界**: 目前可观测的是 SOFA link 和 host diagnostic parent；外部 W3C `traceparent` 仅被 bridge 捕获但未完成语义消费。修复时应严格复用 W3C parser，避免把 process-wide header 错配到其他 session。
