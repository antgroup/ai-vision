# A1 多轮会话识别 + chain 拓扑 {#a1}

- **评分**: ✅
- **结论**: Turn 根 span 唯一 (`gen_ai.span.kind=CHAT` + `gen_ai.operation.name=invoke_agent`) 并携带字符串 `_internal.meta.root="1"`；即使存在上游 `parentSpanId` 也保留逻辑根标记。所有 generation / tool / compaction 全部以根 span_id 为父，构成同级 sibling 链；多次 LLM 调用保留独立 generation span，LLM/TOOL/AGENT 等非 Turn span 不继承 marker。
- **代码引证**:
  - 根 span 类型、逻辑根 marker 与可选上游 parent：`codex/cdxhooks/src/common/otel.rs:1-999` 的 `build_root_span`
  - 子 span 全部父指向 `root_span_id`：`codex/cdxhooks/src/common/otel.rs:1-999` 的 `build_otel_export_request_for_turn`
  - 合成 AGENT 只复制 child Turn 的 input/output，不复制 root marker：`codex/cdxhooks/src/common/otel.rs:1-999` 的 `merge_subagent_sessions_into_otel`
  - 多生成支持（按 `assistant_index` 拆分）：`codex/cdxhooks/src/common/transcript/turn_builder.rs:117-128, 285-790`
- **Replay 例子**:
  - `~/.aivision/cdx/replays/spans_compact.jsonl` 第 1 行：`Turn 1` 之下 5 个 `chat gpt-5.4` + 25 个 `tool Bash`，全部 parent=root（无嵌套）
  - `~/.aivision/cdx/replays/spans_codex-skill.jsonl`：`Turn 1` 之下 4 个 `chat unknown-N` + 3 个 `skill eve-beta` 同级
  - `codex/cdxhooks/tests/fixtures/codex_multi_agent_v2_parent.jsonl`：版本化 multi-agent v2 replay 同时覆盖带 marker 的 Turn 与不带 marker 的合成 AGENT
