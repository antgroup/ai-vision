# AI Vision UI 设计规范

当你被要求编写、修改或审查 AI Vision 产品的前端界面代码时，**必须**加载并遵循此规范。

## 使用方式

1. 读取 [references/design-tokens.md](references/design-tokens.md) 获取完整的设计 Token 定义。
2. 将其中的颜色、字体、圆角、间距规则视为**强约束**，不可自行发挥。
3. 生成代码时，优先使用 CSS 变量 / Design Token，而非硬编码数值。

## 核心原则

- **一致性**：所有页面必须使用同一套 Token，禁止自造颜色或字号
- **亮色模式**：当前规范仅覆盖亮色模式（Light Mode）
- **4px 网格**：所有间距基于 4px 倍数
- **克制用色**：主色调为 #000A1A 的不同透明度，彩色仅用于语义状态

## 违规检查清单

生成代码后自查，如果出现以下情况则需要修正：

- 使用了规范之外的颜色值
- 文字字号不在 12/14/16/20/24px 之内
- 圆角值不在 6/8/10/12px 之内
- 间距不是 4px 的倍数
- 自行添加了 box-shadow（规范未定义阴影）
- 使用了渐变色
- 状态色（成功/失败/告警）用错了色值
