# E3 非真实用户 / 外部触发归因识别

- **评分**: ❌
- **结论**: 当前 Claude Code 未实现 外部触发归因规范要求的 `AIVISION_META_TRIGGER` / `meta.trigger` 输入、`ant.meta.trigger` Resource 输出和 `agentic.turn.trigger` Turn-root 输出。本轮按统一默认基线评为 ❌，不根据 prompt 或 transcript 内容猜测真实用户。
- **代码证据**:
  - `claudecode/cchooks/src/main.rs:183` — 当前 prompt hook 读取的是 `TRACEPARENT`，没有读取 `AIVISION_META_TRIGGER` 或 `meta.trigger`。
  - `claudecode/cchooks/src/common/otel.rs:2941-2950` — 当前通用 Resource wrapper 只接收 agent/environment/scene/collection mode，没有 E3 触发归因输入。
  - `claudecode/cchooks/src/common/otel.rs:846-942` — 当前 Turn root 构造没有 `agentic.turn.trigger` 字段。
- **Replay/source 证据**:
  - `claudecode/cchooks/src/bin/cchooks-replay.rs:612` — replay 通过现有 Turn OTel 构造路径输出，当前没有 `meta.trigger` 历史输入参数。
  - 当前 `~/.aivision/cc/replays/` 样本没有可复现的 `ant.meta.trigger` / `agentic.turn.trigger` E3 正向输出；不能把当前 shell 环境临时设置的变量当作历史 replay source。
- **数据源与缺失原因**: 外部触发归因规范定义了目标输入契约，但当前 Claude Code hook/config/replay 尚未实现该契约。因此缺失属于工程实现缺口，不是根据用户 prompt 推断失败。实现时必须保持 Resource 外部归因与 Turn 宿主观测两层独立，显式环境优先于 `meta.trigger`，非法值降级为 `unknown`。
- **边界**: 不新增或推导布尔型 `is_real_user`；不读取用户名、Git、目录名或 transcript 文本判断用户真实性；本轮不修改 runtime collector、配置解析或 replay。
