# B5 MCP 调用识别

- **评分**：⚪
- **结论**：Pi classifier 具备 `mcp__`/`mcp-` 命名识别代码，但当前 Pi 0.80.6 Golden 配置中的 `getAllTools()` 没有 MCP 工具；没有可信的 runtime MCP source event，不能把命名测试冒充真实 MCP 能力。
- **代码证据**：
  - `pi/observ-pi/src/semantic.ts:65-69,83-101` — 只对进入 hook 的原始 tool name 做 MCP 分类。
  - `pi/pireplay/src/golden/capability-probe.ts:5-17` — capability probe 依据配置工具集合判断 MCP 是否存在。
- **Replay/source 证据**：
  - `pi/pireplay/test/capability-probe.test.ts:32-37` — 无真实 MCP tool 时返回 unsupported，且忽略路径中的 `mcp` 子串。
  - `pi/GOLDEN_BASELINE.md:15-17` — MCP scenario 明确为 skipped，原因是 configured tools 中没有 MCP。
- **数据源缺失根因**：当前 Pi runtime/configuration 没有 MCP 工具或 MCP 协议生命周期事件；后续配置真实 MCP 后再重新评估，不能仅凭 classifier 单测升级。
