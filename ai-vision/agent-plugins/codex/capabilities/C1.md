# C1 LLM 精确耗时 {#c1}

- **评分**: ✅
- **结论**: 每个 generation span 按 invocation 的宿主因果边界计时。`response_item.reasoning` 的完成时间不作为调用起点：首调用使用已有 user submission / turn start，后续使用前一 callback 结束时间；已有独立 ModelEvent 开始证据保持优先。结束时间取本次最早 tool action 或 assistant 输出，duration_ms 与 start/end 一致且非负。
- **边界限制**: 这里记录宿主生命周期，包含原生请求等待，不保证等于 provider 物理 HTTP 时长。缺失开始证据时不能补造上游请求起点，只保留已有观测边界。
