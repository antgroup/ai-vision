# E3 非真实用户 / 外部触发归因识别

- **评分**: ❌
- **结论**: 当前 Hermes 未实现 `AIVISION_META_TRIGGER` / `meta.trigger` 配置输入、`ant.meta.trigger` Resource 输出或 `agentic.turn.trigger` Turn-root 输出。本轮按用户指定的默认未实现基线评为 ❌。
- **代码证据**:
  - `hermes/observ_hermes/config.py:357-424` — 当前配置只合并 exporter、identity 和 agent Resource 环境变量，没有 E3 meta-trigger 解析。
  - `hermes/hermes-core/aivision_hermes_core/resource.py:14-24` — canonical Resource builder 没有 `ant.meta.trigger` 参数。
  - `hermes/hermes-core/aivision_hermes_core/semantic.py:183-206` — 当前 Turn builder 创建 CHAT root，但没有 `agentic.turn.trigger`。
- **Replay/source 证据**:
  - `hermes/hermes-replay/hermes_replay/replay.py:78` — replay 使用现有 Resource/semantic pipeline，没有 E3 输入参数。
  - 当前 Hermes pinned observer envelope/golden 没有 `ant.meta.trigger` 或 `agentic.turn.trigger` 正向样本。
- **数据源与缺失原因**: Hermes observer contract 尚未记录外部任务归因或宿主 Turn trigger。不能使用常驻 observer 的进程 cwd、prompt、用户名或 session 文本推断真实用户；本轮只新增能力标准，不修改 observer/replay。
- **边界**: E3 的缺失属于未实现的统一配置/观测契约，而不是把常驻进程直接判为不适用；Resource 与 Turn 字段独立，非法值必须降级为 `unknown`。
