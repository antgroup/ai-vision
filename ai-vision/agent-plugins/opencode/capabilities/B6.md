# B6 Skill 调用识别 {#b6}

- **评分**：🟡
- **现行能力**：`command.execute.before` 记录真实命令的名称、参数和开始时间，`command.executed` 生成 `agentic.tool.type=skill` 的 TOOL span，通过命令 message ID 防止重复。即使命令完成事件晚于 `session.idle`，仍使用已记录的 Turn context 关联父节点。
- **代码证据**:
  - `opencode/observ-opencode/src/hooks/index.ts:292-321`：before handler 保存命令、参数、历史起点和当前 Turn context。
  - `opencode/observ-opencode/src/hooks/index.ts:328-403`：完成事件去重，按已记录 context 创建关联 Skill span。
- **Replay/source 证据**:
  - [`test-command-skill.ts`](../observ-opencode/scripts/test-command-skill.ts) 覆盖真实参数映射、历史时间、post-idle 父节点、重复完成事件及隐私模式。这是 hook 单元回归；本次 native CLI 的工具读取场景没有执行 skill，不能将它宣称为原生 skill 验收通过。
- **边界**：该命令观测路径不等同于 OpenCode 所有 Agent Skills 行为。新增 skill/tool 类型仍需要实际宿主事件与工具 source 对账。早期“OpenCode 不支持 skill / command 扩展”的描述已经过时。
