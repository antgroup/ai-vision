# E3 非真实用户 / 外部触发归因识别

- **评分**: ❌
- **结论**: 当前 Codex 未实现 外部触发归因规范要求的 `AIVISION_META_TRIGGER` / `meta.trigger` 输入、`ant.meta.trigger` Resource 输出和 `agentic.turn.trigger` Turn-root 输出。本轮按统一默认基线评为 ❌，不从 transcript 文本或 prompt 内容推断真实用户。
- **代码证据**:
  - `codex/cdxhooks/src/main.rs:153` — 当前 prompt hook 读取并传递的是 `TRACEPARENT`，没有 E3 meta-trigger 解析。
  - `codex/cdxhooks/src/common/otel.rs:3728-3737` — 当前 Resource wrapper 没有 E3 归因参数或输出处理。
  - `codex/cdxhooks/src/common/otel.rs:292-430` — 当前 Turn root 构造没有 `agentic.turn.trigger` 属性。
- **Replay/source 证据**:
  - `codex/cdxhooks/src/bin/cdxhooks-replay.rs:574` — replay 使用现有 Turn 构造并未提供 `meta.trigger` / E3 显式输入。
  - 当前 `~/.aivision/cdx/replays/` 与版本化 Codex fixtures 没有包含 `ant.meta.trigger` 或 `agentic.turn.trigger` 的正向样本。
- **数据源与缺失原因**: 本轮将 外部触发归因规范定义的输入视为待接入的统一 source；当前 Codex 没有实现该输入契约，所以按 ❌ 记录工程缺口。不能用 Codex 的 `thread_source`、session metadata 或 prompt 内容替代 `AIVISION_META_TRIGGER`，也不能把 `automation` 机械复制到每个 Turn。
- **边界**: `ant.meta.trigger` 是任务/进程级调用方归因，`agentic.turn.trigger` 是单轮宿主事实；两者可不一致。非法值、冲突或缺失应按标准归一化为 `unknown`，本轮不修改 runtime 或 replay。
