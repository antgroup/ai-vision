# Framework icon sources

## LangChain

`langchain-brand.svg`, `langgraph.svg` and `deep-agents.svg` are unmodified SVG assets served by
the navigation on the official [LangChain brand assets page](https://www.langchain.com/brand-assets).
Retrieved on 2026-10-03.

The [official brand archive](https://cdn.prod.website-files.com/65b8cd72835ceeacd4449a53/6a9998494f7b532d49a38525_langchain-brand-assets.zip)
contains the matching horizontal framework lockups. These standalone square
marks fit the application's compact framework selectors without cropping a lockup.
Their original dark backgrounds and light blue marks are retained for both themes.

| Local file | Official source |
| --- | --- |
| `langchain-brand.svg` | [LangChain navigation icon](https://cdn.prod.website-files.com/65b8cd72835ceeacd4449a53/6989c024409fcfc7e5b8f78f_Frame%202147254707-1.svg) |
| `langgraph.svg` | [LangGraph navigation icon](https://cdn.prod.website-files.com/65b8cd72835ceeacd4449a53/6989c024c2d98286a8fb058f_Frame%202147255166-1.svg) |
| `deep-agents.svg` | [Deep Agents navigation icon](https://cdn.prod.website-files.com/65b8cd72835ceeacd4449a53/6989c02453d869396317aaa3_updated-1.svg) |

Names and marks belong to their respective owners. Follow the official brand
usage guidelines; this notice does not grant additional trademark rights.

## Langfuse integration directory references

The following PNG files are unmodified assets used by the
[Langfuse integration directory](https://langfuse.com/integrations), retrieved on
2026-10-03. They identify the corresponding integrations; they are not AI Vision
or Langfuse product marks.

| Local file | Source |
| --- | --- |
| `claude-agent-sdk.png` | [Claude icon](https://langfuse.com/images/integrations/claude_icon.png) |
| `anthropic.png` | [Anthropic icon](https://langfuse.com/images/integrations/anthropic_icon.png) |
| `google-adk.png` | [Google ADK icon](https://langfuse.com/images/integrations/google_adk_icon.png) |

As in Langfuse's directory, monochrome Anthropic, OpenAI and Instructor marks
use a light CSS presentation in dark mode. The opt-in `logoInvertInDark` catalog
field applies only to monochrome marks; colored artwork retains its original colors.
The downloaded files themselves are unchanged. Names and marks remain the property
of their respective owners; no additional trademark rights are granted here.


## Eino

`eino.png` is the unmodified EINO wordmark from the official CloudWeGo
[`eino-ext` repository](https://github.com/cloudwego/eino-ext/blob/eee37f63ff9548c5eaec48fc157863339f8eda07/components/model/ark/examples/generate_with_image/eino.png),
retrieved on 2026-10-22. The repository distributes it under its
[Apache-2.0 license](https://github.com/cloudwego/eino-ext/blob/eee37f63ff9548c5eaec48fc157863339f8eda07/LICENSE).

The original 1021 × 357 PNG, transparent padding, and purple-blue artwork are
retained. Compact selectors use a wider container to preserve the complete
horizontal wordmark; it is not cropped or inverted in dark mode. The Eino name
and mark belong to their respective owners; no additional trademark rights
are granted here.

SHA-256: `edd4f5c0db30bda1543016961ec72a9900148b87fb53624767a49ba3ffcf16fd`.

## Node.js

`nodejs.svg` is the unmodified Node.js Hex Logo linked from the official
[Node.js branding page](https://nodejs.org/en/about/branding), retrieved on
2026-10-22. Its bytes match the [official repository asset at commit
358cc10e0157ceb28f7adef5331f1db6dc96ce79](https://github.com/nodejs/nodejs.org/blob/358cc10e0157ceb28f7adef5331f1db6dc96ce79/apps/site/public/static/logos/nodejsHex.svg).
The original 200 × 200 SVG canvas, complete hexagon, and green artwork are
retained in both themes; the mark is not cropped, recolored, or inverted.
