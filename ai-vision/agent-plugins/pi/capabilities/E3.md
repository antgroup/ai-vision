# E3 非真实用户 / 外部触发归因识别

- **评分**: ❌
- **结论**: 当前 Pi 未实现 `AIVISION_META_TRIGGER` / `meta.trigger` 配置输入，也未输出 `ant.meta.trigger` Resource 或 `agentic.turn.trigger` Turn-root 事实。本轮按统一默认基线评为 ❌。
- **代码证据**:
  - `pi/observ-pi/src/config.ts:267-280` — 当前 Resource configuration 处理 agent identity/collection mode，没有 E3 meta-trigger 字段。
  - `pi/observ-pi/src/telemetry.ts:80-125` — 当前 telemetry runtime 从既有 config Resource 创建 provider，没有 E3 归因。
  - `pi/observ-pi/src/semantic.ts:375-390` — 当前 Turn root 创建既有 CHAT/root marker，但没有 `agentic.turn.trigger`。
- **Replay/source 证据**:
  - `pi/pireplay/src/raw-envelope.ts:1-20` — replay raw envelope 没有 E3 trigger input 字段。
  - 当前 Pi Golden/replay 样本没有 `ant.meta.trigger` / `agentic.turn.trigger` 正向输出，不能把测试进程环境当作历史 source。
- **数据源与缺失原因**: Pi host contract 尚未实现 规范定义的显式外部归因输入与 Turn trigger source；这是本轮要求新增的工程能力缺口。不能通过 `ctx.cwd`、用户名、prompt 或 session id 判断真实用户。
- **边界**: 外部归因和宿主 Turn 观测必须分层记录；缺失/非法值为 `unknown`，不新增布尔 `is_real_user`，不把 Resource 字段复制到每个 span。
