# D3 异步子 agent 调用识别 {#d3}

- **评分**: ⚪
- **结论**: kimi-cli 当前不支持异步子 agent 模式（无 `run_in_background` 语义），wire.jsonl 中无对应事件类型，数据源根本不可获取。
- **代码证据**：`kimi/kimihooks/src/hooks/stop.rs:1-1100` 的 wire 重建路径没有 async/background subagent 事件；`kimi/kimihooks/src/common/otel.rs:1-2800` 没有异步子 agent 跨 trace 构造。
- **Replay/source 证据**：现有 wire fixture 只覆盖同步 `SubagentStart → SubagentStop` 生命周期，没有异步 child trace。
- **数据源缺失根因**: kimi-cli 的子 agent 调用均为同步阻塞模式（SubagentStart → 等待 → SubagentStop），不存在异步分叉后独立 trace 上报的场景。
